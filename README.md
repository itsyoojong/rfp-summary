# RFP Summary

제안요청서(PDF)의 주요 정보를 요약하는 도구를 만드는 개인 학습 프로젝트입니다.

## 현재 진행 상황

pypdf로 PDF를 읽고 페이지별 텍스트를 추출했습니다.
각 페이지의 번호와 텍스트를 딕셔너리로 묶어 리스트에 보관하고,
페이지별 글자 수와 일부 본문을 확인했습니다.

요약 모델 연동과 결과 평가는 아직 구현하지 않았습니다.

## 실행 환경

Python 3.13, pypdf 6.5.0, VS Code Jupyter Notebook을 사용했습니다.

## 실행 방법

노트북에서 사용할 Python 환경에 requirements.txt의 패키지를 설치합니다.
프로젝트 폴더 안에 data 폴더를 만들고 실습 문서를 sample.pdf로 넣습니다.
01_read_pdf.ipynb를 열어 코드 셀을 위에서부터 순서대로 실행합니다.

실습 PDF 원문은 저장소에 포함하지 않습니다.

## 확인한 한계

텍스트 추출 과정에서 띄어쓰기가 사라지거나 표의 내용이 붙는 현상을 확인했습니다.
추출된 글자 수만으로 원문이 정확하게 복원됐다고 판단할 수는 없습니다.
