## 해결 내용

- 환경변수 `RFP_ENABLE_DISK_CACHE` 기본값은 `false`. 값이 명시적으로 `true`인 경우만 디스크 저장·복원한다. 공개 기본 모드에서는 기존 캐시도 읽지 않는다.
- 그룹·페이지 결과는 세션별로 유지하며, 내용 해시가 다른 문서 또는 업로드 해제 시 초기화한다. 세션 종료 후 복원은 보장하지 않는다.
- 로컬 캐시 읽기·쓰기 실패 시 이전 문서 결과를 섞지 않으며 현재 세션 분석을 계속할 수 있다.
- Groq로 문서 텍스트를 전송한다는 안내를 디스크 저장 정책과 별도로 표시한다.
- 대표값과 판단 상태를 우선 표시하고 선택 후보의 인용 검증 상태를 함께 표시한다. 일부 인용 실패를 전체 검증 성공으로 표시하지 않는다.
- K-sure 검색, PDF 5페이지 전용 출력, 주석 처리 UI, 사용하지 않는 import·상태, API 오류 응답 본문 출력과 잘못된 검증 안내를 제거했다.

## 테스트 결과

기존 환경에는 `python` 명령이 없고 가상환경 의존성 일부가 누락돼 있었다. `requirements.txt`를 프로젝트 `.venv`에 설치한 후 아래 명령을 실행했다. API 요청은 실행하지 않았다.

```bash
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m compileall -q app.py src tests scripts
```

- **22개 PASS / FAIL 0 / ERROR 0**: 후보 선택 4, JSON 저장·복원 4, 세션 정책 5, 원문·사업비 8, Streamlit AppTest 1.
- 변경 전에는 unittest 집계 4개와 import 시 실행되는 assert 검증이 있었다. 기존 assert 검증을 정식 테스트로 전환했다.
- AppTest는 파일 업로더·PDF 추출·분석 응답을 모의한다. 그룹 분석, 진행 완료, 최종 출력 경로, 일반 재실행 유지, 별도 세션 분리, 문서 변경·업로드 해제 초기화, 개별 페이지 분석, 캐시 함수 미호출을 확인했다. 실제 브라우저나 Groq 응답 검증은 아니다.
- `compileall`: 문법 검증 통과. AppTest로 앱 import·실행 확인.
- `git diff --check` 및 `git diff --cached --check`: 오류 없음.
- `git check-ignore`: macOS 파일, 별도 프로젝트, 비밀 설정, 가상환경, Python 캐시, PDF, 분석 캐시, 로컬 보고서 제외 확인.

기존 로컬 PDF·베이스라인·캐시와 기준 답안을 **읽기만 하는 평가**도 실행했다. 기존 보고서는 덮어쓰지 않았다.

| LMS 기존 자동 일치 | 2/4 |
| LMS 후보 선택 후 자동 일치 | 4/4 |
| LMS 후보 탐지 | 4/4 |

## 남은 한계와 확인 범위

추가 개발·평가가 필요한 항목은 인용 페이지 오지정, 복잡한 PDF 레이아웃, 장문 사업목적 품질, 제한적인 평가 문서 수, 제한된 금액·조건 비교 규칙이다. OCR·RAG·벡터 DB·인증은 구현하지 않았다.

현재 MVP의 운영 한계로 세션 종료 시 결과 소실, 명시적 로컬 캐시의 사용자 구분 없는 동일 문서 재사용이 있다. 로컬 캐시는 공개 배포에서 활성화하지 않아야 한다. 기본 캐시 차단은 Groq 전송이나 인프라 전반의 데이터 보존 정책을 바꾸지 않는다.

**미검증:** 실제 Groq 분석 호출, Streamlit Cloud 재배포·정상 운영 여부, 실제 브라우저의 업로드·연결 생명주기. 배포 전에는 README의 수동 점검 순서로 API 키 설정, 캐시 비활성화, 페이지·그룹 분석, 재실행 유지, 문서 변경, 별도 시크릿 세션 분리, 최종 검증 상세, 서버 캐시 파일 미생성을 확인해야 한다.

## Git 커밋 준비

최초 상태는 `main`에서 `.DS_Store` 사용자 변경 1개였다. 로컬 파일을 보존하고 `git rm --cached -- .DS_Store`만 실행했다. 이 추적 해제는 이미 인덱스에 반영되어 있고 나머지 변경은 스테이징하지 않았다. `AI_Virtual_Team/`은 추적 중인 파일이 없어 제거할 대상이 없었으며 제외 규칙을 적용했다.

커밋에 포함할 대상은 위 변경 파일 표 전체다. 사용자 PDF, 기존 `data/`의 캐시·베이스라인·평가 보고서, `.env`, `.streamlit/secrets.toml`, `.venv/`, `AI_Virtual_Team/` 및 로컬 `.DS_Store` 파일은 제외한다. 평가 기준 답안은 변경하지 않았다. 기존 파일·Git 히스토리를 삭제하거나 재작성하지 않았다.

```bash
git status --short
git diff --stat
git diff --cached --stat
git diff --check
git diff --cached --check
```

새 파일은 `git diff --stat`에 포함되지 않으므로 `git status`에서 함께 검토해야 한다. 커밋·Push·배포는 수행하지 않았다.
