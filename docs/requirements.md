# RFP Insight — 프로젝트 요구사항 v0.1

## 1. 프로젝트 개요

**프로젝트 목적:** 제안요청서(RFP)를 분석하고, 핵심 정보를 구조화하여 문서 검토 시간을 줄이는 AI 웹 애플리케이션 개발.

**대상 사용자:** 공공기관 입찰에 참여하는 기업의 실무자, 제안서 작성 담당자, 입찰 컨설턴트.

**해결할 문제:** 긴 제안요청서에서 예산, 일정, 필수 요구사항 등을 확인하는 데 시간이 소요되며, 문서 검토 과정에서 중요한 조건이 누락될 수 있음.

## 2. 핵심 기능

- F01: PDF 문서 업로드 및 페이지별 텍스트 추출
- F02: 사업명, 사업비, 사업기간, 주요 요구사항, 제출기한 자동 추출
- F03: 추출한 정보를 JSON 형식으로 구조화
- F04: 사용자의 질문과 관련된 문서 구간 검색
- F05: 검색한 문서를 바탕으로 답변 생성
- F06: 답변에 근거가 되는 원문과 페이지 번호 표시

## 3. 예외 처리

- 파일 형식이 잘못된 경우 오류 안내
- 텍스트 추출이 불가능한 스캔 PDF는 지원하지 않음을 안내
- 문서에서 확인되지 않는 항목은 임의로 생성하지 않음
- API 요청 실패 및 사용량 제한 발생 시 사용자에게 상태 안내

## 4. 기술 구성

- 언어: Python
- PDF 처리: pypdf
- LLM API: Groq
- 웹 UI: Streamlit
- RAG: 청킹, 임베딩, 벡터 검색 방식 검토
- 형상 관리: Git / GitHub
- 배포: MVP 완성 이후 결정

## 5. 품질 평가

여러 RFP 문서를 대상으로 주요 항목 추출의 정확성, 누락 여부, 근거 페이지의 정확성, 응답 시간을 측정한다.

금액, VAT 포함 여부, 기간 및 예산 조건은 각각 검증한다.

## 6. MVP 제외 범위

- 사용자 회원가입 및 로그인
- 여러 사용자의 동시 문서 관리
- HWP 및 스캔 PDF OCR 처리
- 자체 LLM 사전학습 또는 미세조정
- 자동 입찰 제안서 작성

## 7. MVP 완료 기준

사용자가 텍스트 기반 PDF 한 개를 업로드하면 핵심 정보를 확인하고, 문서에 관해 질문하며, 답변의 근거 페이지를 검토할 수 있어야 한다.

서로 다른 RFP 최소 3개로 기능을 시험하고, 발견한 오류와 해결 과정을 기록한다.
